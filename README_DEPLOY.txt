LOAD LAB — WEB VERSION

Easiest free hosting: GitHub Pages.
1. Create a public repository named load-lab in your GitHub account.
2. Upload index.html, manifest.webmanifest, icon.svg, and sw.js to the repository root (not the ZIP itself).
3. Go to Settings > Pages > Build and deployment > Deploy from a branch. Choose main and / (root), then Save.
4. Wait for GitHub to publish. The link is normally https://YOUR_USERNAME.github.io/load-lab/ .
5. Open the link on your iPhone in Safari. Use Share > Add to Home Screen if desired.

Alternative: upload the contents of this folder to any static HTTPS host.

Important: this is a prototype. Optional ad rewards are simulated; there is no real advertising or real-money checkout. Saved coins/costumes are browser-local. Test thoroughly before promoting widely.
